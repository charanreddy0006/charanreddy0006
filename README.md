### Things I've been building

A few projects that represent different parts of what I'm interested in:

**SmartForm AI**
An intelligent form builder and response management platform built during my Infosys Springboard internship.

**Zomato Data Engineering Platform**
A larger project where I've been experimenting with pipelines, Snowflake, dbt, Airflow, AI enrichment, RAG and Text-to-SQL.

**RAGLens**
A document-question answering project exploring retrieval, embeddings, vector search and grounded responses.

**Weather ETL Pipeline**
A smaller project focused on API extraction, transformation, storage, automation and monitoring.

**BGE-M3 / RAG Experiments**
Experiments around embeddings, similarity, reranking and evaluating generated answers.

**SQL-A-Day**
A long-running SQL practice repository covering everything from fundamentals to more advanced SQL problems.

**And a lot of smaller projects...**
